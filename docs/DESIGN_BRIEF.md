# Bano.ai Design Brief

Product: turns Hinglish engineering lectures into transcripts (Devanagari + Roman), notes, summaries, glossary, questions and quizzes. Users: Indian engineering students. Tone: clear, direct, student-friendly, slightly Hinglish. Never hype.

Feel: a well-used study notebook, not a SaaS template. Calm, readable, focused on text.

Look:
- Background warm off-white (#FAF7F2), text near-black ink (#1C1B1A), one accent: marigold/highlighter yellow (#F2B705) used like a highlighter on key terms and active states. One secondary: deep ink blue (#1F3A5F) for links and buttons. Dark mode: warm charcoal, same accent.
- No purple/blue gradients, no glassmorphism, no glowing shadows, no emoji as icons, no stock illustration, no gradient text.
- Type: a serif for headings (Source Serif 4 or Newsreader), a clean sans for UI (Inter or DM Sans), Noto Sans Devanagari for Hindi text. Load with next/font. Body 16-18px, generous line height for transcripts.
- Layout: left-aligned, text-first, thin 1px borders, restrained radius (6-8px), real whitespace. Transcript view is a two-column reading layout with timestamps in a margin. Technical terms get a highlighter-style underline. Off-topic segments are muted, not hidden.
- Icons: one small line-icon set (lucide-react) used sparingly, always with text labels.
- Motion: only subtle (150-200ms) hover/focus and progress. No bouncing or parallax.
- Accessibility: AA contrast, visible focus rings, keyboard navigation, mobile-first (students use phones).

Copy rules (real, specific, no filler):
- Hero: "Lecture Hinglish mein thi. Notes ab saaf hain." Subline: "Upload ya record karo. Transcript, notes, glossary aur quiz — ek jagah." (Devanagari/English variants allowed.)
- No "Welcome back!", "Unlock", "Supercharge", "Revolutionize", "seamless", "powerful AI". Never claim accuracy without the benchmark number and its caveat.
- Buttons are verbs: "Lecture upload karo", "Quiz banao", "Notes export karo".
- Status text is plain: "Audio taiyaar ho raha hai", "Transcript ban raha hai (Gnani)". Errors say what happened and what to do.
- Every AI-made section is labelled: "AI ne banaya — teacher ka exact statement nahi."
- Benchmark page states: 3 scripted clips, small test, not a general ranking.
- Empty states are useful ("Abhi koi lecture nahi. 30 second ka clip upload karke dekho.").
